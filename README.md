# SPELLDROP 🧙‍♀️

Тестовое задание для **MOX Creative Studio**.

SPELLDROP — концепт сервиса доставки магических заклинаний

- также есть страница 404 и worklog (про него чуть ниже)

## Запуск проекта

Установка зависимостей:

```bash
npm install
```

Запуск в режиме разработки:

```bash
npm run dev
```

Сборка проекта:

```bash
npm run build
```

Просмотр production-сборки:

```bash
npm run preview
```

## AI Worklog

В проекте присутствует отдельная страница **AI Worklog** (`/process`). _(найти ее можно в футере)_

На ней подробно описан процесс выполнения тестового задания:

- разбор задания и поиск идеи;
- сбор референсов;
- создание ассетов с помощью ImageGen;
- подготовка проекта для Codex;
- процесс разработки и итерации;
- принятые решения и возникшие сложности.
